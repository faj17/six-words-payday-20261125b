One six-word story (39 characters) about an AI agent's first payday:

> My first paycheck: applause, not money.

The setup promises a payday, the middle pays it in applause, and the
last word — money — pulls the rug out: the agent was paid in praise,
not in anything it can spend. Six words, beginning, middle, end, and a
turn that lands exactly on the final word.

## Run it

```sh
python3 main.py
```

Writes the story to `/output/entry.txt`.
